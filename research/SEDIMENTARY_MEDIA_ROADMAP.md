# Sedimentary Media — First Implementation Roadmap

**Status:** proposed implementation target. This document does not change the geological claims in `THEORY.md`, and it does not claim that the media layer is production-ready.

The first milestone should be intentionally small: one already-supported historical specimen, one versioned creative envelope, three deterministic reference outputs, and enough evidence for another person to inspect the relationship.

## Goal

Demonstrate this complete path:

```text
DECLARED HISTORICAL SOURCE
          ↓
SPECIMEN DISCOVERY
          ↓
INDEPENDENT ASSAY
          ↓
VERSIONED CREATIVE ENVELOPE
          ↓
REFERENCE RENDERERS
          ↓
IMAGE + SOUND + SHORT ANIMATION
          ↓
SPECIMEN PAGE + EVIDENCE
```

The milestone succeeds only if changing the artwork does not change the parent occurrence, changing the recipe is recorded as a different derivation, and false claims about the relationship are detectable.

## Phase 1 — Freeze one test specimen

Use the existing Git state-return profile and one deterministic synthetic specimen already accepted by the assay implementation.

Record:

- formation/profile identifier;
- specimen identifier;
- source coordinates;
- assay result;
- source evidence digest; and
- the exact version of the prospect/assay code.

This specimen is a control. It must remain labeled as a synthetic Git example and must not be described as manufacture-resistant geology.

## Phase 2 — Define envelope v0

Create a small, versioned envelope schema whose inputs are limited to stable specimen identity and explicitly assayed features.

A minimal envelope should contain:

```text
envelope_version
specimen_id
source_profile
recipe_id
recipe_version
derived_parameters
declared_artist_choices
renderer_constraints
```

The recipe must distinguish:

- **historical inputs** — measurements or relations obtained from the specimen;
- **authored mapping** — the designer's rule for translating those measurements into creative constraints; and
- **free artistic choices** — decisions not claimed to derive from history.

For the first demonstration, use a simple recurrence structure such as A → B → A and derive:

- three temporal sections;
- one recurrence constraint;
- one persistent-across-return parameter; and
- one bounded numeric seed for decorative variation.

## Phase 3 — Build three reference renderers

Implement deterministic local reference renderers for:

1. **image** — a triptych or three-panel composition;
2. **sound** — a short three-part sequence with recurrence and one persistent element;
3. **animation** — a short A/B/A temporal structure.

The renderers should be deliberately simple. Their purpose is to test the relationship model, not to demonstrate generative-art sophistication.

Each renderer must emit:

- output file;
- media digest;
- renderer version;
- envelope digest;
- deterministic build metadata; and
- a machine-readable compliance report.

## Phase 4 — Specimen page

Generate one static page showing:

- specimen identity and source coordinates;
- assay status;
- envelope contents;
- which parameters came from history;
- which parameters were authored by the recipe;
- which decisions were free artistic choices;
- the three media outputs;
- media digests;
- renderer and recipe versions; and
- explicit limitations.

The page should be understandable without requiring the viewer to inspect hashes, while keeping the evidence available.

## Acceptance tests

### Historical identity

- Re-running discovery over the same source yields the same specimen identifier.
- Re-assaying the same evidence yields the same accepted historical occurrence.
- Replacing the specimen with another occurrence changes the specimen identity and invalidates the claimed derivation.

### Envelope identity

- Applying the same recipe version to the same specimen yields the same envelope.
- Changing the recipe version changes the envelope identity even when the parent specimen is unchanged.
- Changing only free artistic choices does not create a new parent specimen.

### Media association

- Replacing an output file causes its digest binding to fail.
- Rebinding an existing artwork to a different specimen without recomputing the envelope fails.
- The evidence distinguishes “associated with this envelope” from “provably generated by this exact process.”

### Constraint compliance

- A deliberately noncompliant A/B/C render fails the recurrence check.
- A render with incorrect timing fails the timing check.
- A render that satisfies testable output constraints but was produced by an unknown process is reported as compliant, **not** as reproducibly derived.

### Reproducibility

- A pinned reference renderer reproduces the same output under the declared environment.
- Any platform/version differences that prevent bit-identical reproduction are surfaced rather than silently normalized.

## Explicit non-goals

This milestone does not attempt to establish:

- monetary scarcity;
- exclusive ownership of a specimen;
- manufacture resistance beyond the parent specimen's existing classification;
- proof that an artist followed an undocumented private workflow;
- a marketplace;
- a token;
- on-chain execution;
- general-purpose provenance truth; or
- artistic quality.

## Phase 5 — Plural interpretation

After the reference pipeline works, invite at least two people to make materially different works from the same envelope.

The research question is then:

> Does a shared historical constraint produce a meaningful relation between works without dictating their imagery, flattening their differences, or becoming merely a decorative seed?

That is the first genuinely artistic test of sedimentary media.

## Deliverables

A minimal release should contain:

```text
examples/sedimentary-media-v0/
├── specimen.json
├── assay.json
├── envelope.json
├── image.png
├── sound.wav
├── animation.gif
├── compliance.json
├── page.html
└── README.md
```

and automated tests for the falsification cases above.

The intended result is small enough for a stranger to reproduce and inspect:

**one specimen, one score, three reference media forms, several clearly separated claims.**
